# Test Strategy

## Goal

要件と主要リスクをどのテストで検証するか明確にする。

## Topics

- Test scope
- Unit tests
- Integration tests
- E2E tests
- Platform-specific tests
- Manual tests
- Test environment
- Acceptance criteria coverage

## Complete when

- 主要な要件に検証方法がある
- テストレベルの役割分担が明確
- 重要な統合部分の検証方法が明確
- 必要な実行環境や外部依存の扱いが明確
- 主要な未検証リスクが把握されている
