プロジェクトの初期情報からプロジェクトoverviewを作成する。

## 手順

1. ユーザーの初期情報を読む。
2. skill `grill-me-with-goal` を使い、Overview 作成に必要な不足情報を一問ずつ確認する。
3. 十分な情報が揃ったら `./docs/PROJECT_OVERVIEW.md` を作成する。

## Overview に含めるもの

* 目的
* 対象ユーザー
* プラットフォーム
* 主要機能
* 想定規模
* 外部サービス
* 主な制約
* 既知の前提
* 未決事項

詳細設計には踏み込まない。
