## 要件照合

- **C-23**: `ContextBuilder` は選択済み Agent Core Context の `state.concerns` を空配列にする。一方で `PostgresAgentContextLoader` は Context 構築前の完全 `CurrentAgentState` を `persistentState` として Runtime 専用に返す。
- **C-06 / C-24**: `AgentRuntime` は `persistentState` を Harness と Experience Integration へ渡さず、Concern proposal の patch 基準にだけ用いる。従って選択ContextにConcernがなくても、既存Concernを含む完全Stateに proposal が適用される。
- **必須 PostgreSQL 回帰**: `tests/integration/persistence.test.ts` の `C-06, C-24: retains a Concern beyond the context selection boundary when a normal Event commits` は、`AgentRuntime.process` → `PostgresRuntimePersistence.loadInput` → `PostgresAgentContextLoader.load` の通常Event経路を通す。Harness 入力の `state.concerns` が空であることと、commit 後の DB に既存 `active-after-history` および proposal による `new-concern` がともに残ることを検証している。
