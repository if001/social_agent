# Issue #035 レビュー

## 対象

- Memory根拠Eventが16件を超えた既存データの正規化
- 以後のMemory update / reconciliationでの上限維持

## 結果

重大・高の指摘はなし。

レビューで指摘された以下を実装に反映した。

- 正規化後に `PostgresReflectionRepository.refresh()` まで成功する統合テストを追加した。
- CLI引数を純粋なparserへ分離し、dry-run既定値、`--agent-id`、`--apply`、不正引数を単体テストした。
- 正規化は根拠配列だけを変更し、`updated_at`を更新しない。根拠を消しただけの古いMemoryが再検討候補の新しさを得ないようにした。
