# Issue #017 レビュー（2026-11-07）

## 対象

- `issues/017-experience-integration-after-agent-core.md`
- AgentCore schema 縮小、Experience Integration、永続化trace、debug UI、関連一次文書

## 結果

- 受け入れ条件に関する未解決の CRITICAL / HIGH 指摘はなし。
- 初回レビューで見つかった入力Context欠落、Memory evidence検証、Memory versionを失う候補変換、trace未記載は修正した。
- 再実行経路は`pending`/`failed`の定期drainと原子的claimを用いる。成功時は過去の`failure_reason`をclearする。

## 確認した根拠

- AgentCoreはDesire / Actionのみを永続出力に持つ。
- Integrationは初回commit後に入力断面を保存し、Memory / Mood / Relationshipだけを処理する。
- Integration失敗はRuntimeの初回commitとoutboxを巻き戻さない。
- debug UIはEvent traceのCore後処理としてIntegration input / output / applied / failureを表示する。
