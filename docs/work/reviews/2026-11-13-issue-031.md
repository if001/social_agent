resolution, persistence audit, and Debug UI projection.

## Findings addressed

  IDs, local handles, evidence IDs, and cursors.
- Formation binds natural-language candidates to only the fixed Event batch;
  unsupported candidates finish as `no-op`.

  completed/no-op anchor so retry does not re-run it.
- `reflection_resolutions` stores resolver version, query summary, selected
  Event IDs, rejected candidates, score, temporal decision, and outcome.
- Debug UI projects this audit without exposing prompts or chain-of-thought.
