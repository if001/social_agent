# Issue 066 Review

- Reviewed scope: `issues/066-gate-observed-peer-messages-before-agent-core.md`
- Result: accepted after follow-up fixes.

## Fixed findings

1. `ignore` Event was excluded from recent context but not Memory Reconciliation evidence. The reconciliation query now excludes `observation_gate_decisions.decision = 'ignore'`.
2. A fail-open Gate audit could be lost when the normal Agent Core failed. Failure persistence now records the Gate audit with the failed Event.
3. Concurrent Runtime workers could each call the Gate before a receipt existed. `gate-processing` receipt reservation now admits one worker and releases only after a failed normal run.
4. The timeline now labels observed messages with `Gate: engage` or `Gate: ignore`; detail includes the bounded Gate audit.
5. `retrievalCount` records the number of RAG calls, not the number of retrieved Memory records.
