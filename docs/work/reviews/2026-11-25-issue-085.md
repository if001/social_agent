# Issue #085 review

## Scope

`issues/085-observe-concern-lifecycle-health-without-automation.md` と FR-25 / NFR-12 を基準に、Concern lifecycleのDebug UI表示差分を確認した。

## Result

要件に関わる指摘なし。

- Agentごとの所有者filter付きSELECTだけで、現在のstatus数、Activity集計、未進展候補、embedding近傍候補を取得している。
- UI表示は読み取り専用で、Concern lifecycle操作・閾値判定・自動closeを追加していない。
- embedding近傍は候補表示だけで、統合や終了を確定しない。
- satisfied / abandonedは履歴推定をせず、現在のstatus件数として表示する。
