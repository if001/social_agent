## 確認結果

- `tool-result-model-view.ts` は既存の `ToolRegistry.projectResult(..., "conversation-history")` と `projectInput` を唯一の投影実装として利用している。Agent CoreのTool履歴とExperience Integration / Event Experience repairの間に独自のTool種別・本文制御はない。
- content-read Toolの本文は後続モデル入力から除外され、通常Tool結果は既存の上限付き表示規則を利用する。保存済みの完全なTool実行結果は変更しない。
- Experience Integrationだけに短いMemory候補schemaを置き、ReflectionおよびMemory Writeの契約を狭めていない。
- 短縮したsystem promptとrepair指示は、Experience、Relationship、Focus Concernの許可fieldとRuntime所有fieldを引き続き指定している。
